# Mensalão — Direção de design

Definida pelo Renato em 01/10/2026. É a entrada do agente de UX (`ux`) para escrever `docs/design.md`.

- Estética **moderna e minimalista**: poucos elementos por tela, bastante respiro, hierarquia clara pelos números (valores e datas em destaque), sem ornamentos.
- **Cores que remetam a dinheiro**: tons de verde (verde-cédula, verde-esmeralda, menta claro) como base da identidade, com neutros limpos. Um tom dourado/âmbar pode servir de acento pontual.
- As cores de alerta (vence logo, reajuste que subiu, excluir) precisam se distinguir claramente do verde da marca, para não se confundirem com estados positivos.
- Acessibilidade continua obrigatória (contraste WCAG AA, foco visível), como pede a Definição técnica do backlog.
